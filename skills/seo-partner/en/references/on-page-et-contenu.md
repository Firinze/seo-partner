# Reference Guide: On-Page Optimization & Content Briefs

## 1. Core HTML & Metadata Signals (`R-ONPAGE-01` to `R-ONPAGE-08`)

- **`<title>` (`R-ONPAGE-01`, `02`, `03`)**: Mandatory and unique across all public pages. Recommended display length: **50 to 60 characters**, front-loading the primary query and value proposition.
- **`<meta name="description">` (`R-ONPAGE-04`, `05`, `06`)**: Mandatory and unique. Recommended display length: **150 to 160 characters**, written to maximize organic CTR.
- **`<h1>` (`R-ONPAGE-07`)**: Exactly **one `H1`** per page matching the primary user intent, followed by a clean `H2` -> `H3` outline.
- **Images (`R-ONPAGE-08`)**: Descriptive `alt` attribute required on all meaningful images, explicit `width`/`height` to prevent CLS, modern formats (`WebP`/`AVIF`).

## 2. E-E-A-T & Conversion Architecture

- First-hand evidence (quantified case studies, clear methodology, named author, dated official citations).
- Clear Call to Action (CTA) above the fold and at content conclusion.
- Descriptive internal anchor text connecting cluster articles to core commercial pillar pages.
