# Reference Guide: Measurement, Dashboard & ROI Analysis

## 1. Core KPI Hierarchy

- **Leading indicators (Search Console)**: Valid indexed pages, non-branded impressions, average position on target queries (especially striking-distance positions 4 to 15).
- **Traffic & engagement**: Organic clicks, CTR by page template.
- **Business outcomes**: Qualified leads, demo requests, calls, revenue attributed to organic search.

## 2. Realistic Impact Modeling

Always express forecasts as a conservative range (low / base / upside scenario) stating explicit CTR and conversion rate assumptions—never as guaranteed rankings.
